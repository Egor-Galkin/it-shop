# ITshop — Платформа для продажи электронной техники

Полноценная платформа для продажи электронной техники с расширенной аналитикой, управлением заказами и генерацией отчётности. Проект разработан с акцентом на производительность, безопасность и удобство использования.

## Демо

- Фронтенд: https://it-shop-web.onrender.com
- Бэкенд API: https://it-shop-d38x.onrender.com

> Примечание: Проект размещён на бесплатном тарифе Render. Хостинг находится за рубежом, поэтому для доступа из некоторых регионов может потребоваться VPN. Бэкенд может переходить в спящий режим при простое — первый запрос после простоя может занять 30-60 секунд на "пробуждение".

## Технологический стек

### Фронтенд (папка client)

- Next.js 16 с App Router
- TypeScript
- SCSS Modules для стилизации
- Redux Toolkit для управления состоянием
- Axios для HTTP-запросов
- Chart.js для визуализации статистики
- pdfkit для генерации PDF-чеков на клиенте

### Бэкенд (папка server)

- NestJS 10 (монолитная архитектура)
- TypeScript
- Prisma ORM для работы с базой данных
- PostgreSQL 18
- Passport.js + JWT для аутентификации
- class-validator для валидации DTO
- Multer для обработки загружаемых файлов
- pdfkit для генерации PDF-отчётов на сервере

### Инфраструктура

- Render для хостинга фронтенда, бэкенда и базы данных
- Git и GitHub для контроля версий

## Архитектура проекта

Проект организован как монорепозиторий с разделением на клиентскую и серверную части.

### Структура репозитория

```text
it-shop/
├── client/
│   ├── src/
│   │   ├── app/                    # Страницы и layout'ы (App Router)
│   │   ├── components/             # Переиспользуемые UI-компоненты
│   │   ├── store/                  # Redux slices и хуки
│   │   └── lib/                    # Утилиты: axios, генерация PDF
│   ├── public/                     # Статические файлы
│   └── next.config.ts              # Конфигурация Next.js
│
├── server/
│   ├── src/
│   │   ├── auth/                   # Модуль аутентификации: JWT, guards
│   │   ├── devices/                # CRUD товаров и управление изображениями
│   │   ├── basket/                 # Корзина, заказы, чеки
│   │   ├── ratings/                # Отзывы и модерация
│   │   ├── stats/                  # Аналитика и отчёты
│   │   ├── prisma/                 # Prisma service и конфигурация
│   │   └── main.ts                 # Точка входа в приложение
│   ├── prisma/
│   │   ├── schema.prisma           # Схема базы данных
│   │   ├── migrations/             # История миграций
│   │   └── seed.ts                 # Скрипт заполнения тестовыми данными
│   └── package.json
│
├── .gitignore
└── README.md
```


### Взаимодействие фронтенда и бэкенда

- Связь осуществляется через REST API
- HTTP-клиент: axios с интерцепторами для автоматической подстановки JWT-токена в заголовок Authorization
- Базовый URL API задаётся через переменную окружения NEXT_PUBLIC_API_URL
- Ответы бэкенда имеют единый формат ошибок: `{ message, error, statusCode }`

## Роли и функционал

### Гость (неавторизованный пользователь)

- Просмотр главной страницы, каталога, карточек товаров
- Поиск и фильтрация товаров по типу, бренду, цене
- Сортировка товаров по цене (с учётом активной скидки) и по рейтингу
- Просмотр отзывов к товарам (без возможности добавления)
- Регистрация и авторизация

### Клиент (авторизованный пользователь)

- Весь функционал гостя, плюс:
- Управление корзиной:
  - Добавление и удаление товаров, изменение количества
  - Выбор способа доставки (курьер или самовывоз из пункта выдачи) с учётом стоимости в итоговой сумме
  - Оформление заказа с генерацией PDF-чека
- История заказов:
  - Просмотр статусов заказов: "В обработке", "Выдан", "Отменён"
  - Повторная загрузка чека в формате PDF
  - Отмена заказа с возвратом средств (если статус позволяет)
- Личный кабинет:
  - Просмотр и редактирование профиля
  - Смена пароля
  - Управление своими отзывами: редактирование и удаление

### Администратор

- Доступ к админ-панели с CRUD-операциями для всех основных сущностей:
  - Товары: название, цена, тип, бренд, изображения, характеристики
  - Категории и бренды
  - Скидки с указанием периода действия
  - Пользователи (просмотр, блокировка)
  - Отзывы (модерация: скрыть или показать описание)
  - Способы доставки
- Расширенная аналитика:
  - Общая статистика: количество зарегистрированных клиентов, новые пользователи за неделю, общее количество заказов, выручка
  - Динамика по периодам (день, неделя, месяц)
  - Детализация по брендам, типам товаров, пользователям, заказам, способам доставки
  - Визуализация данных через Chart.js с выбором типа диаграммы (столбчатая, круговая, линейная)
- Генерация отчётов:
  - Экспорт статистики в PDF с оформлением
  - Фильтрация по датам и категориям перед экспортом

## Структура страниц

### Главная страница

- Слайдер реализован как отдельный переиспользуемый компонент
- Изображения загружаются с плавным появлением благодаря компоненту Image из Next.js
- Единый layout для всех страниц включает:
  - Шапку с навигацией через компонент NavLink из Next.js
  - Футер с контактной информацией и ссылками
  - Визуализированный фоновый паттерн

### Авторизация и регистрация

- Аутентификация через JWT-токен
- Пароли пользователей хранятся в базе данных в хешированном виде (bcrypt)
- Валидация полей формы на клиенте и сервере

### Каталог товаров

- Поиск с функцией debounce для снижения нагрузки на сервер
- Фильтрация по типу товара и бренду
- Сортировка:
  - По цене (с учётом текущей скидки)
  - По рейтингу (рассчитывается на основе оценок пользователей)
- Пагинация для оптимизации производительности при большом количестве товаров
- Карточка товара отображает: название, цену, рейтинг, основное изображение
- При наведении на карточку показываются дополнительные изображения товара
- Плавающий элемент корзины с возможностью:
  - Просмотра добавленных товаров
  - Изменения количества
  - Выбора типа доставки (влияет на итоговую сумму)

### Страница товара

- Полная информация о товаре: название, цена, тип, бренд, характеристики, изображения
- Блок отзывов всех пользователей с возможностью сортировки по дате или оценке
- Авторизованный пользователь может оставить новый отзыв или отредактировать свой существующий
- Администратор может выборочно скрывать описания отзывов (модерация)
- Администратор может редактировать все параметры товара:
  - Наименование, тип, бренд, цена
  - Характеристики (название и описание)
  - Основное и дополнительные изображения
  - Скидка с указанием периода действия
- Валидация всех полей при редактировании

### Профиль пользователя

- Возможность смены текущего пароля

#### Профиль клиента

- Управление текущей корзиной:
  - Просмотр перечня товаров и их количества
  - Изменение количества или удаление позиций
  - Выбор типа доставки
- История заказов:
  - Просмотр списка заказов с их статусами
  - Возможность оплаты заказа
  - Скачивание оформленного PDF-чека с содержимым и итоговой ценой
  - Отмена заказа и возврат средств (если статус позволяет)
  - Статусы заказов: "В процессе", "Выдан на пункте выдачи", "Забран через самовывоз"

#### Профиль администратора

- Управление (админ-панель):
  - CRUD-операции для всех основных таблиц
  - Сортировка, поиск, пагинация в списках
  - Валидация вводимых данных
  - Расчёт и отображение связанных данных (например, количество отзывов у клиента, соотношение его заказов: всего, готовые, в процессе)
- Статистика:
  - Общая статистика: зарегистрированные клиенты, прирост за неделю, общее количество заказов, выручка
  - Формирование диаграмм через библиотеку Chart.js:
    - Типы: столбчатые, круговые, линейные графики
    - Фильтры: по брендам, типам товаров, пользователям, заказам, способам доставки
    - Выбор периода для анализа
  - Оформление и скачивание отчёта по статистике в формате PDF

## Установка и запуск локально

### Предварительные требования

- Node.js версии 20.x или выше
- PostgreSQL версии 15.x или выше (локально или через Docker)
- Git

### Клонирование репозитория

```bash
git clone https://github.com/Egor-Galkin/it-shop.git
cd it-shop
```

### Настройка и запуск бэкенда

```bash
cd server

# Установка зависимостей
npm install

# Копирование файла переменных окружения
cp .env.example .env
# Отредактируйте .env: укажите DATABASE_URL, JWT_SECRET и другие параметры

# Применение миграций к локальной базе данных
npx prisma migrate deploy

# Заполнение базы данных тестовыми данными
npx prisma db seed

# Запуск в режиме разработки
npm run start:dev
```

Бэкенд будет доступен по адресу: http://localhost:3001

### Настройка и запуск фронтенда

```bash
cd ../client

# Установка зависимостей
npm install

# Копирование файла переменных окружения
cp .env.example .env
# Убедитесь, что NEXT_PUBLIC_API_URL=http://localhost:3001

# Запуск в режиме разработки
npm run dev
```

Фронтенд будет доступен по адресу: http://localhost:3000

### Полезные команды

| Команда | Описание |
|---|---|
| `cd server && npx prisma studio` | Открыть Prisma Studio для просмотра данных в БД |
| `cd server && npx prisma migrate dev --name <name>` | Создать новую миграцию с описанием изменений |
| `cd server && npx prisma db pull` | Синхронизировать схему Prisma с существующей базой данных |
| `cd client && npm run build` | Собрать фронтенд для продакшена |
| `cd server && npm run build` | Скомпилировать бэкенд (NestJS) для продакшена |

## Деплой на Render

Проект развёрнут на платформе Render в конфигурации монорепозитория.

### Команды сборки для Render

#### Фронтенд (папка client):

`npm install && npm run build`

Команда запуска: npm run start

#### Бэкенд (папка server):

`npm install && npx prisma generate && npx prisma migrate deploy && npm run build`

Команда запуска: node dist/main

> При каждом деплое бэкенда автоматически применяются все миграции Prisma и генерируется Prisma Client.

## База данных: миграции и сиды

### Миграции Prisma

Все изменения схемы базы данных управляются через Prisma Migrate. История миграций хранится в папке server/prisma/migrations/.

Для применения миграций к новой базе данных используется команда:

`npx prisma migrate deploy`

### Сиды (начальные данные)

Скрипт server/prisma/seed.ts заполняет базу данных тестовыми данными:

- Бренды и типы товаров
- Товары с характеристиками и изображениями
- Пользователи (клиенты и администратор)
- Отзывы, корзины, заказы, способы доставки

Для запуска сидов:

`npx prisma db seed`

>Примечание: При создании новой базы данных на Render миграции применяются автоматически в процессе сборки. Сиды можно запустить вручную через консоль сервиса или локально после подключения к удалённой БД.
